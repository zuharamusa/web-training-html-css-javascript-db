# web-training-html-css-javascript-db

A small training repository with example HTML, CSS, JavaScript, and simple database-related exercises. Includes a basic site (`index.html`) and a contact page (`contact.html`) used for practicing front-end layouts and form handling.

**Author:** zuharamusa

## Contents
- `index.html` — Main demo page
- `contact.html` — Contact form example

## Getting Started

To view the project locally, open `index.html` or `contact.html` in your browser. For a simple local web server (recommended), run from the repository root:

```bash
# Python 3 simple server
python3 -m http.server 8000

# Then open http://localhost:8000 in your browser
```

## Development

- Edit the HTML/CSS/JS files using your preferred editor.
- Refresh the browser to see changes. Use a live-reload extension or simple server for faster iteration.
